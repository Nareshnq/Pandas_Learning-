# 🐼 Pandas DataFrame & Data Handling

End-to-end data preparation project using Pandas and NumPy, focusing on structured data transformation, feature engineering, categorical creation, datetime processing, missing value handling, and dataset merging to support machine learning pipelines. Demonstrates clean, scalable data preprocessing practices.

## What This Project Covers
- Data cleaning and validation (handling missing values, type conversions)
- Feature engineering and derived columns
- Categorical feature creation
- Datetime processing and time-based transformations
- Dataset merging and joins using Pandas
- Structured data preparation for analytics and machine learning workflows

## Datasets Used
- Structured CSV datasets used for hands-on data preprocessing practice
- Includes numerical, categorical, and datetime features
- Designed to simulate real-world business and analytical data scenarios

The datasets live in `datasets/` — `bios.csv`, `coffee.csv`, and `noc_regions.csv`.

Source: Public Kaggle dataset

## Tools & Skills Demonstrated
- Python
- Pandas
- NumPy
- Data cleaning and preprocessing
- Feature engineering
- Datetime handling
- Dataset merging and joins
- Analytics and machine learning data preparation

## How to Run
1. Install Python with Pandas and NumPy (`pip install pandas numpy`), plus Jupyter if you want to run the notebook interactively.
2. Open `notebook/Pandas_Practice.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
3. Run the cells in order — the practice datasets are in `datasets/`.
